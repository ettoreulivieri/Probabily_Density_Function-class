pdf_gen documentation
=====================

.. .. image:: _static/logo_small.png
..    :alt: Project logo
..    :width: 200px
..    :align: left

`pdf_gen` is a |Python| package designed to reconstruct and evaluate probability
density functions (PDFs) from experimental or simulated data points.

It leverages |numpy|, |scipy|, and |matplotlib| to provide fast and efficient density
estimation and visualization tools.
